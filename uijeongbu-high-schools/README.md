# 의정부시 고등학교 스트리트맵

Leaflet과 OpenStreetMap 타일을 사용하는 단일 HTML 지도입니다.

- 대상: 의정부시 소재 고등학교 16개교
- 기능: 학교 마커, 학교 유형·주소 팝업, Google 지도 및 OpenStreetMap 위치 링크
- 실행: `index.html`을 정적 웹서버 또는 GitHub Pages에서 열기

## 데이터 참고

학교 목록과 주소는 공개 교육정보를 교차 확인해 작성했습니다.

- [의정부시 고등학교 목록](https://studyholic.com/m/review/total_school/School_Total_List.asp?grade=3&official_sido_code=41&official_sigungu_code=41150)
- [의정부교육지원청 고교학점제 워크북 PDF](https://www.goe.go.kr/resource/old/BBSMSTR_000000000163/BBS_202309130120451282.pdf)
- 지도 타일·일부 학교 좌표: [OpenStreetMap](https://www.openstreetmap.org/), [Photon](https://photon.komoot.io/)

좌표는 지도 표시용이며, 학교의 공식 위치 확인이나 통학·부동산·안전 판단에는 해당 학교 및 공식 지도 서비스의 최신 정보를 다시 확인해야 합니다.
